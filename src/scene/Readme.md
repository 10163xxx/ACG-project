# Greenhouse 场景重构设计方案

## 1. 项目目标

将现有 Greenhouse 场景改造为一个具有真实空间层次、自然日光照明和合理植物陈列的热带植物展示温室（Tropical Botanical Conservatory）。

本次改造不推翻现有建筑和资产基础，而是在保留温室主体结构、红掌模型和蕨类模型的基础上，重新设计：

- 建筑材质与玻璃表现
- 植物的空间布局和展示层次
- 相机位置与构图
- 环境光和人工补光
- 新植物模型与展示设施

最终画面应当突出植物本身，温室建筑负责提供空间氛围和视觉框架，不应成为画面的主要视觉对象。

### 设计原则

1. **固定整体风格**：采用明亮、自然的热带植物展示温室，不在现代展厅、摄影棚和丛林风格之间反复切换。
2. **保留现有基础**：不重新制作温室主体，不删除已经接入的红掌和蕨类模型。
3. **先解决结构问题**：优先处理玻璃、环境光、相机和植物布局，再增加模型。
4. **自然光优先**：以户外 HDR 环境光为主要照明来源，使用大面积面光源补光，避免依赖多个点光源。
5. **控制模型数量**：新增模型必须提供不同的叶片形态或空间体量，避免重复导入相似植物。
6. **保证可维护性**：模型来源、许可证、纹理和转换记录必须完整保存在项目中。

## 2. 场景整体设计

### 2.1 建筑尺寸与坐标约定

保留现有温室主体尺寸：

| 方向 | 范围 |
|---|---|
| X | -4 ~ 4 |
| Y | 0 ~ 6.2 |
| Z | -8 ~ 4 |

坐标约定：

- 入口位于 Z 正方向，约 `z = 4`
- 后墙位于 `z = -8`
- 中央通道沿 Z 轴延伸
- X 轴中心线为 `x = 0`
- 地面高度为 `y = 0`

本次不改变建筑的整体长宽高，主要调整内部空间组织和视觉表现。

### 2.2 空间布局

采用中央主展台、两侧植物陈列区和中央参观通道的布局。

| 区域 | 主要内容 | 设计作用 |
|---|---|---|
| 前景 | 两侧蕨类及低矮盆栽 | 建立空间纵深 |
| 中景 | 红掌中央主展台 | 形成主要视觉焦点 |
| 后景 | 大型观叶植物 | 填补背景空间，建立高度层次 |
| 左右两侧 | 长条花槽、植物展示架 | 丰富温室内部陈列 |
| 中轴 | 石材步道 | 引导视线进入场景 |

中央通道保持畅通，原则上不在 `x = -0.8 ~ 0.8` 范围内放置大型盆栽或花槽。

植物不采用完全对称排列。左右两侧应形成视觉呼应，但前后位置和植物高度应有适当差异。

### 2.3 植物位置规划

以下位置作为第一版布局基准，实际导入时应结合模型包围盒和叶片朝向微调。

| 对象 | 参考中心位置 | 参考高度 | 说明 |
|---|---|---:|---|
| 红掌 | `(0, 1.0, -2.2)` | 2.35 | 中央主体，保留现有模型 |
| 左前蕨类 | `(-2.55, 0, 0.2)` | 1.65 | 前景左侧 |
| 右中蕨类 | `(2.55, 0, -3.8)` | 1.85 | 中景右侧 |
| 左后大型植物 | `(-2.5, 0, -6.0)` | 约 2.3 | 新增 |
| 右后大型植物 | `(2.5, 0, -6.0)` | 约 2.5 | 新增 |
| 左侧花槽 | `x ≈ -3.1` | 依模型调整 | 沿侧墙布置 |
| 右侧花槽 | `x ≈ 3.1` | 依模型调整 | 沿侧墙布置 |

注意：植物位置表示模型的底部定位或参考中心，具体取决于 OBJ Loader 的 `base_position` 语义。调整时必须统一使用模型底部定位，不能把模型中心和底部位置混用。

### 2.4 中央展台

红掌继续作为唯一的主要展示对象。

展台应具有以下特点：

- 位于温室中央偏后位置。
- 高度约 0.95 个场景单位。
- 使用浅暖灰色石材。
- 减少目前明显的铜色金属包边。
- 不使用过多装饰结构。
- 展台不能遮挡红掌底部，也不能与叶片产生明显穿插。

## 3. 建筑与材质设计

### 3.1 温室骨架

保留现有立柱、横梁、屋顶横梁和后墙分隔结构。

骨架采用深森林绿色金属，表现为低反射、偏哑光的金属结构。

建议初始参数：

| 参数 | 数值 |
|---|---|
| Base Color | `(0.045, 0.095, 0.065)` |
| Metallic | `0.45` |
| Roughness | `0.48` |

避免使用接近纯黑的金属材质，否则会使建筑结构过于沉重。

### 3.2 地面

地面改为暖灰色哑光石材。

建议参数：

| 参数 | 数值 |
|---|---|
| Base Color | `(0.48, 0.46, 0.41)` |
| Metallic | `0.0` |
| Roughness | `0.72` |

地面不应产生大面积镜面反射，也不应比植物主体更亮。

### 3.3 展台与花盆

展台采用浅暖灰色石材：

| 参数 | 数值 |
|---|---|
| Base Color | `(0.48, 0.43, 0.34)` |
| Metallic | `0.0` |
| Roughness | `0.62` |

花盆采用暗陶土色或深灰陶瓷：

- 暗陶土：暖棕红色调。
- 深灰陶瓷：低饱和度、粗糙表面。
- 土壤：深棕色漫反射材质。

花盆应当有材质差异，但不能使用过高的金属度或反射强度。

### 3.4 玻璃结构

当前温室的玻璃面片使用普通 `PrincipledBSDF`：

```cpp
auto glass_pane = std::make_shared<PrincipledBSDF>(
    Vec3(0.72, 0.75, 0.77), 0.02, 0.12);
```

这种材质并不具备真正的透光效果，实际表现更接近灰白色反光面。

#### 第一阶段处理

暂时移除不透光的玻璃面片，保留温室金属骨架。

涉及 `greenhouse_scene.h` 中：

- `Side glazing`
- `Two pitched roof slopes`
- `Rear glazed wall and mullions`

删除上述区域中用于表现玻璃的 Quad，但保留立柱、横梁、屋顶骨架和后墙分隔结构。

这一阶段的目的是先让环境光进入温室，避免不透明玻璃面片阻挡光线。

#### 后续完善

第一阶段完成后，再实现专用薄玻璃材质。

要求：

- 支持反射和透射。
- 正确处理薄面片的法线方向。
- 不错误地创建封闭介质边界。
- 不破坏现有 MediumState 和折射路径处理。
- 透明玻璃不能影响正常的光源采样和阴影计算。

不能直接把所有玻璃 Quad 替换成普通 Dielectric，就认为玻璃实现已经完成。

## 4. 照明系统设计

### 4.1 总体原则

照明采用自然日光体系：

1. 户外 HDR 环境光提供主要自然照明。
2. 大面积面光源提供柔和补光。
3. 第一阶段不使用明显的点光源。

不再采用目前由两盏点光源和一块小型发光面组成的室内展柜式照明。

### 4.2 HDR 环境光

目前 `main.cpp` 使用：

```cpp
environment.load("assets/environments/studio_small_01_2k.hdr");
```

计划替换为户外晴天环境 HDR。

候选资源：

`kloofendal_48d_partly_cloudy_puresky`

来源：

https://polyhaven.com/hdris

下载后放入：

```text
assets/
└── environments/
    └── kloofendal_48d_partly_cloudy_puresky.hdr
```

选择标准：

- 有明确的天空方向和自然日光。
- 环境整体明亮。
- 不使用摄影棚环境。
- 避免过于戏剧化的日落或强烈色偏。

替换前必须检查 `EnvironmentMap::evaluate()` 和 `sample_direction()` 的方向约定，确保环境贴图中的太阳方向与实际照明方向一致。

同时在 `assets/ASSET_CREDITS.md` 中记录来源、作者和许可证。

### 4.3 大面积面光源

将现有小型发光 Quad 替换为更大的柔和面光源。

建议初始实现：

```cpp
auto emitter = std::make_shared<DiffuseLight>(
    Vec3(1.5, 1.65, 1.4)
);

world.add(std::make_shared<Quad>(
    Vec3(-1.8, 5.35, -3.0),
    Vec3(3.6, 0.0, 0.0),
    Vec3(0.0, 0.0, 2.0),
    emitter
));
```

面积约为 7.2 个平方场景单位，朝向下方。

它主要负责补充中央展台和附近植物的照明，不应取代 HDR 环境光的主导地位。

后续应根据实际渲染结果调整面光源强度，而不是不断增加光源数量。

### 4.4 点光源

第一阶段关闭 Greenhouse 场景中的两盏点光源：

```cpp
s.point_lights.clear();
```

暂时不使用局部点光源，避免画面出现不自然的局部亮斑。

如果后续发现某些区域确实缺乏照明，再考虑增加一盏低强度辅助光源。

## 5. 相机与构图

目前相机位置：

```cpp
from = Vec3(5.8, 3.8, 9);
at = Vec3(0, 2.55, -1.8);
fov = 46;
```

该角度容易使温室侧面和建筑结构占据过多画面。

调整为：

```cpp
from = Vec3(4.2, 3.2, 10.0);
at = Vec3(0.0, 2.0, -2.4);
fov = 43;
aperture = 0.0;
focus = 13.0;
```

设计目标：

- 从入口向温室内部观察。
- 保留适度的斜向透视。
- 让红掌成为画面视觉中心。
- 保留左右植物陈列和后景纵深。
- 不让屋顶横梁遮挡主体。
- 不使用景深模糊掩盖场景布局问题。

第一阶段保持原始输出分辨率：

```cpp
s.width = 640;
s.height = 360;
```

## 6. 新增模型与资产管理

新增模型只引入三种不同职责的植物。

| 模型类型 | 主要用途 | 放置区域 |
|---|---|---|
| 龟背竹或类似大型裂叶植物 | 增加大型叶片轮廓 | 后景 |
| 竹芋类宽叶植物 | 增加叶片形态差异 | 中后景 |
| 低矮盆栽 | 填充花槽和展示架 | 前景、侧边 |

资源优先从 Poly Haven 获取：

https://polyhaven.com/models

优先选择 CC0 模型。

### 模型导入要求

每个新增模型都必须检查：

1. OBJ 文件是否完整。
2. MTL 是否正确引用。
3. 漫反射纹理是否能正常加载。
4. 透明贴图 `map_d` 是否正确处理。
5. UV 坐标是否完整。
6. 模型法线是否合理。
7. 模型缩放和底部定位是否正确。
8. 是否存在过多不必要的三角形。

特别注意叶片透明贴图：

- 不能出现矩形或方形叶片轮廓。
- 不能出现黑色背景。
- 不能因为透明材质而产生明显的阴影错误。
- 应检查透明贴图是否与漫反射贴图正确对应。

### Credit 管理

每个外部资产必须在 `assets/ASSET_CREDITS.md` 中记录：

- 资产名称。
- 本地路径。
- 原始下载地址。
- 作者。
- 许可证。
- 修改和转换说明。

不能只记录网站名称而不记录具体资产来源。

## 7. 实施计划

本次改造分成两个完整阶段。

### 第一阶段：重构现有场景

涉及文件：

```text
src/scene/greenhouse_scene.h
src/scene/scene_factory.h
src/main.cpp
assets/environments/
assets/ASSET_CREDITS.md
```

具体任务：

1. 修改地面、骨架、展台和花盆材质。
2. 暂时移除不透光玻璃面片。
3. 保留温室金属骨架。
4. 调整现有红掌和蕨类的布局。
5. 简化中央展台。
6. 替换户外 HDR 环境。
7. 增加大型柔和面光源。
8. 关闭原有两盏点光源。
9. 调整相机位置和视角。

第一阶段目标是：即使不增加任何新模型，现有场景也应该具有合理的空间构图和自然的明暗关系。

### 第二阶段：完善植物陈列

涉及文件：

```text
src/scene/greenhouse_scene.h
assets/
assets/ASSET_CREDITS.md
```

具体任务：

1. 导入大型裂叶植物。
2. 导入宽叶植物。
3. 导入低矮盆栽。
4. 增加左右两侧长条花槽。
5. 根据模型实际尺寸调整缩放和定位。
6. 检查所有模型的纹理和透明贴图。
7. 统一植物材质和陈列密度。
8. 最后调整环境光和面光源强度。

第二阶段完成后，再考虑实现真正的薄玻璃材质。

## 8. 测试与验收

第一阶段不需要反复进行高质量正式渲染。

使用已有 Preview 和 Draft 模式：

```powershell
cmake --build build --config Release

.\scripts\render.ps1 -Config Release -Scene Greenhouse -Preview

.\scripts\render.ps1 -Config Release -Scene Greenhouse -Draft
```

### 第一阶段验收标准

- [ ] 温室建筑结构仍然清晰。
- [ ] 不再出现大面积不透光灰白玻璃面片。
- [ ] 红掌是画面主要视觉主体。
- [ ] 两盆蕨类形成合理的前中景关系。
- [ ] 中央通道保持畅通。
- [ ] 相机视角能够体现温室纵深。
- [ ] 环境光能够进入温室内部。
- [ ] 面光源能够柔和补光。
- [ ] 不出现明显的局部过曝和强烈反光。
- [ ] 植物叶片能够辨认形状和纹理。

### 第二阶段验收标准

- [ ] 新增植物具有明显不同的叶片形态。
- [ ] 后景不再空旷。
- [ ] 左右花槽与植物陈列自然融合。
- [ ] 新增 OBJ/MTL 纹理正确加载。
- [ ] 透明叶片没有方形边界或黑色背景。
- [ ] 所有外部资产均有完整 credit。
- [ ] 植物之间不存在明显穿插。
- [ ] 最终画面仍然突出红掌主体。

## 9. 最终目标

最终场景应当具有以下特征：

1. 一座结构清晰、明亮通透的热带植物温室。
2. 中央红掌是主要展示对象。
3. 前景、中景和后景具有明显的空间层次。
4. 两侧植物陈列丰富但不拥挤。
5. 日光提供自然的方向性照明。
6. 面光源负责柔和补光。
7. 地面、展台、花盆和金属骨架具有明确的材质差异。
8. 植物模型具有真实的纹理和透明叶片轮廓。

本次设计不以增加模型数量或单纯提高亮度为目标，而是以**构图合理、空间真实、照明自然、资产完整**作为最终评价标准。

所有后续修改均围绕这一设计方向展开，不再反复改变温室的整体风格和空间布局。
