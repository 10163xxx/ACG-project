# Greenhouse Scene

The final showcase scene will be developed in this directory.

Planned organization:

- models/: scene-specific geometry and imported models.
- materials/: material definitions and configuration notes.
- textures/: color, normal, roughness and other texture maps.
- environments/: scene-specific environment maps.

Prefer reusable geometry and procedural materials where practical.

Record the original source, author and license of every external asset
in assets/ASSET_CREDITS.md.
